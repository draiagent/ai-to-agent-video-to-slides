# 影片收藏了一堆，教材還是生不出來？用 Agent Skills，把觀念變成教學簡報

看完一部好影片，心想：「這個觀念很適合拿來教同事！」但打開簡報，卻不知道從哪裡開始。整理重點、寫旁白、配字幕，再加動畫，忙了一輪，內容還是零散。

**真正卡住的，往往是沒有把「看懂」轉成「教會別人」的流程。**

## 如何把參考影片變成自己的教材？

先拆解影片的觀念，註明原作者，再拿公司的案例重新說明。

例如，參考影片談工作標準化，就用公司「新人處理客訴」的情境，帶讀者走過問題、方法與前後差異。文字、畫面與案例自行製作，讓抽象觀念變成能操作的步驟。

## VAD 與 VAC，分別幫你做什麼？

**VAD 先想清楚：給誰看？看完要會什麼？**

開工前確認用途、長度、設計、聲音、字幕與交付項目，減少做到一半才發現方向不對。

**VAC 把想法變成八個可驗收的關卡：**

確認需求 → 分析影片 → 撰寫內容 → 檢查內容 → 編寫分鏡 → 製作影片 → 準備發布素材 → 最終檢查。

搭配 Agent Skills，讓 Agent 按照明確規格執行；您負責方向與關鍵確認。

## 影片做完，就能交付了嗎？

還要備齊指定的封面圖、章節時間軸、影片說明文、網誌文章與字幕檔。

時間軸必須量測最終影片；標題、署名與用詞要跨檔一致。網誌則以清楚標題、直接回答和具體案例，兼顧 SEO、AEO 與 GEO 的內容需求。

**畫面漂亮是第一眼，讀完能實作，才是教材的價值。**

明天就選一部參考影片，搭配一個公司案例，先寫下：「同事看完後，能完成哪件事？」這句答案，就是製作的起點。
