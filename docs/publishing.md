# 發布素材規格

| 素材 | 必要內容 |
|---|---|
| 封面圖 | 主題清楚、符合既定設計與品牌 |
| 章節時間軸 | 最終影片每頁起始時間與標題，第一行 0:00 |
| 影片說明文 | 摘要＋章節時間軸＋課後行動＋署名＋標籤 |
| 網誌文章 | 依旁白整理觀念、同一公司案例與問答 |
| 字幕檔 | 繁體中文，對應最終語音與時間碼 |

時間碼量測最終成片，不採用分鏡預估。時間軸只有一份來源，影片說明文與網誌共用。是否啟用平台章節功能仍須上架後檢查，本文件不保證只填 0:00 即會生效。

## 網誌八段

1. 標題：含主要關鍵字。
2. 摘要：前三句直接回答核心問題。
3. 影片嵌入與時間軸：使用實際影片網址與同一份時間軸；未上架前不編造網址。
4. 正文：依內容稿順序，用問題小標與直接回答。
5. 案例：同一場景，附前後對照。
6. 常見問答：3～5 題，每題 2～3 句。
7. 作者與來源：作者身分、署名、概念原作者。
8. 行動呼籲：明天可以做的第一步。

SEO 讓內容容易被搜尋；AEO 讓答案清楚直接；GEO 讓生成式 AI 更容易理解與引用。這些寫作原則不保證排名或引用。主要關鍵字自然出現在標題、摘要與至少兩個小標，不堆疊。直接引用的旁白須與字幕逐字一致，改寫段落須保留原意。

本專案 docs/blog.md 為方法論介紹文章，不是某支已完成影片的上架網誌；因此未附虛構時間軸或影片嵌入。
