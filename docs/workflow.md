# VAD／VAC 完整工作流程

## 任務目標與分工

拆解影片的觀念，做出教學的簡報。用 Agent Skills，拿公司案例，完成語音、字幕、動畫與發布素材。

VAD：先定義對象、目的、角色、流程與驗收。VAC：將上述設計落成可執行的任務圖卡。需求確認者決定方向；製作 Agent 執行；獨立核對者驗收。

## 名詞

| 名詞 | 定義 |
|---|---|
| 參考影片 | 分析觀念的來源；不複製原文與原畫面，註明原作者 |
| Agent Skills | Agent 執行任務時遵循的技能與工作規範；實際能力取決於工具與環境 |
| 需求表 | 開工前確定對象、設計、聲音、長度、交付與關鍵字的表格 |
| 設計系統 | 全片一致的配色、字體、卡片與版面規則 |
| 觀念摘要 | 來源架構與觀念重點，標註原作者 |
| 內容稿 | 每頁標題與一件要教的事，以公司案例說明 |
| 檢查報告 | 五個內容問題的檢查結果、嚴重性與修正紀錄 |
| 分鏡表 | 畫面元素、逐字旁白、元素出現語句與預估秒數 |
| 影片 | 簡報、語音、字幕與動畫合成的最終成品 |
| 發布素材 | 封面圖、章節時間軸、影片說明文、網誌文章、字幕檔 |

## 八關

| 關 | 名稱 | 輸入 | 產出 | 確認方式 |
|---|---|---|---|---|
| 1 | 確認需求 | 想法與素材 | 含設計系統的需求表 | 您確認 |
| 2 | 分析影片 | 參考影片 | 註明來源的觀念摘要 | 您確認借用觀念 |
| 3 | 撰寫內容 | 觀念摘要＋公司案例 | 內容稿 | 您確認 |
| 4 | 檢查內容 | 內容稿 | 檢查報告 | 嚴重問題歸零；超過 2 個回第 3 關重寫 |
| 5 | 編寫分鏡 | 內容稿＋設計系統 | 分鏡表 | 您確認後鎖定內容與旁白 |
| 6 | 製作影片 | 錄音 → 逐字稿 → 定稿字幕 | 影片 | 字幕確認後，依字幕時間對齊動畫，最後才燒入；每完成幾頁抽圖確認 |
| 7 | 準備發布素材 | 影片＋分鏡表 | 需求指定的五項素材 | 依需求交付，您確認 |
| 8 | 最終檢查 | 全部檔案 | 檢查結果 | 未參與製作的人或 Agent 核對 |

嚴重問題包括事實錯誤、核心步驟缺漏、無法達成教學目標。1～2 個亦須修正至零；超過 2 個重寫。其他問題須記錄處置，不得默認忽略。

## 內容順序

讀者痛點 → 原因 → 解決方法 → 同一公司案例 → 前後差別 → 方法限制 → 明天第一步。

## 五個檢查問題

1. 拿掉這段，讀者會少學到什麼？答不出來就刪。
2. 是否同一場景從頭用到尾？
3. 看完能做哪件以前不會做的事？
4. 每頁是否回答它的標題？
5. 名詞、標題、署名、設計與關鍵字，在影片、字幕、說明文與網誌是否一致？

## 四條規則與失敗處理

- 第五關鎖定後改內容，回第三關往下更新，重新核對所有相依檔案。
- 參考影片只取觀念，文字、畫面、案例自行製作；來源與素材使用範圍須記錄。
- 不自行增刪品牌元素與設計系統，不確定先問。
- 字幕依實際錄音定稿，確認後才燒入。

讀不到來源時，標記缺少資料並請提供逐字稿，不憑標題腦補。語音或影片工具不可用時，保留已確認內容並記錄阻礙，不將分鏡假報為成片。每次記錄修改次數、完成時間與各關一次通過情形。
